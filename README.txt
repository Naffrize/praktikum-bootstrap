Tiga perubahan dari contoh modul:
1. Membuat tema profil mahasiswa dengan palet warna kuning, oranye, dan coral.
2. Mengubah quote pada halaman utama menjadi quote Tan Malaka dan menambahkan nama sumbernya.
3. Mengubah tombol menggunakan komponen Bootstrap seperti variant primary, outline, ukuran besar/kecil, tombol bulat, dan tombol full-width.

Penjelasan perubahan button:
Pada bagian button, saya menggunakan class Bootstrap seperti btn-primary dan btn-outline-light untuk membedakan tombol utama dan tombol tambahan. Saya juga menggunakan btn-lg untuk tombol yang lebih besar, btn-sm untuk tombol yang lebih kecil, rounded-circle untuk tombol media sosial, dan w-100 supaya tombol Send Message memenuhi lebar form.

Kendala dan cara mengatasinya:
Kendala: Pada awalnya saya masih bingung membedakan penggunaan class button Bootstrap, sehingga ukuran dan tampilan tombol belum konsisten.
Solusi: Saya membaca dokumentasi Bootstrap dan mencoba beberapa class seperti btn-primary, btn-outline-light, btn-lg, btn-sm, rounded-circle, dan w-100. Setelah itu, setiap tombol bisa disesuaikan dengan kegunaannya.
